How it works

01 · Data stays yours

Every account belongs to exactly one store. Every query is filtered by that store ID at the database layer — your uploads, predictions and dashboards are never visible to another store.

02 · A model that generalizes

Rather than training a separate, data-starved model per store, Smart Inventory Advisor trains one global model with store- and product-aware encodings — so small stores still benefit from patterns learned across the whole network.

03 · Recent data matters more

Training uses exponential decay weighting: weight = exp(-λ × days_since_record). Recent sales pull harder on the model than data from months ago, so the forecast adapts as trends shift without forgetting seasonal patterns entirely.
